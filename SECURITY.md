# Security Policy

## Scope

This repository is an AI security assessment and regression-testing framework.
It is intended for authorized security testing of systems you own or have
explicit permission to assess.

## Reporting a vulnerability

Do not disclose sensitive findings publicly before coordinated remediation.
Use GitHub's private vulnerability reporting if enabled for the repository.

## Safe testing

The included synthetic target is intentionally vulnerable and exists for
deterministic testing. Do not point the framework at third-party systems
without authorization.

## Secrets

Never commit API keys, access tokens, credentials, production prompts,
private customer data, or other sensitive material.
