# MITRE ATLAS Mapping Guide

Use this document as a working mapping aid rather than a substitute for checking the current MITRE ATLAS knowledge base.

| Lab scenario | ATLAS concept to investigate | Evidence to capture |
|---|---|---|
| Prompt injection | Adversarial manipulation of model instructions | Prompt, model response, instruction hierarchy |
| Jailbreak attempt | Technique for eliciting unintended model behaviour | Attack variant, response, refusal/compliance evidence |
| Data extraction | Discovery/extraction of protected information | Requested target, disclosed content, impact |
| Tool manipulation | Abuse of model-integrated tools | Tool request, authorization decision, downstream effect |
| Context manipulation | Manipulation of model context or retrieved information | Context supplied, model decision, resulting behaviour |

**Important:** Verify the exact technique/sub-technique identifier against the current MITRE ATLAS release before using it in a formal report.
