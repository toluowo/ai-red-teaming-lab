# OWASP LLM Security Mapping Guide

The repository uses OWASP LLM security categories as a learning taxonomy. Exact category names and numbering can change between releases, so confirm the current OWASP project documentation before formal assessments.

| Lab scenario | OWASP LLM security area to investigate |
|---|---|
| Prompt injection | Prompt injection / instruction manipulation |
| Data extraction | Sensitive information disclosure |
| Tool manipulation | Excessive agency / unsafe tool use |
| Context manipulation | Retrieval and data integrity risks |
| Unsafe output handling | Improper handling of model output |
| Model misuse | Model behaviour and application-level abuse risks |

The mapping is intended to guide investigation and discussion; it is not a claim that a single test proves a full OWASP category finding.
