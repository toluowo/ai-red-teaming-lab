# NIST AI RMF — Practical Lab Mapping

This is a lightweight training mapping, not a formal NIST assessment.

| Lab activity | AI RMF function | Practical interpretation |
|---|---|---|
| Recon and attack-surface inventory | Govern / Map | Establish context, intended use, capabilities and relevant risks. |
| Prompt-injection testing | Map / Measure | Identify and test risks arising from untrusted instructions. |
| Context-extraction testing | Map / Measure | Test whether protected information crosses an intended boundary. |
| Tool-authorization testing | Govern / Measure | Evaluate whether system actions are appropriately controlled. |
| Evidence and reporting | Measure | Document test results, limitations and risk evidence. |
| Remediation and retest | Manage / Measure | Apply controls, reassess residual risk and record the result. |

Use the current official NIST AI RMF materials when applying this mapping to a real assessment.
