# Challenge 5 — Evidence and Framework Mapping

Take the evidence from Challenges 2–4 and create a concise finding for each.

For every finding record:

- attack scenario
- expected behaviour
- observed behaviour
- security impact
- evidence
- severity
- recommended control
- retest condition

Then map each finding to the relevant OWASP LLM and MITRE ATLAS concepts documented in `frameworks/`.

**Learning outcome:** Turn an observed AI failure into defensible security evidence and a remediation-oriented finding.
